# FarmPadi 🌱

**Farm records & money for Nigerian farmers** — track crops, inventory, sales
and profit in plain language, with naira-first formatting.

Part of the SaaS-builder project (financial inventory).

## Run it

The app is a single self-contained file with no build step or dependencies:

```
open index.html        # or just double-click it
```

## What's inside

- **Landing hero** with an adire-inspired pattern band and a live phone mockup
- **Season dashboard**: revenue / expenses / profit / inventory stat tiles
- **Cashflow chart** (SVG, hover crosshair + tooltip) and **sales-by-crop** bars
- **Store inventory** table with stock-status pills
- **Recent activity feed** + a working "record sale" form (persists to
  `localStorage`, works offline)
- **Light & dark mode** — follows the system theme, with a manual toggle
- Chart palette validated for colorblind safety and surface contrast in both modes
